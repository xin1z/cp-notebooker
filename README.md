# cp-notebooker

A competitive-programming study companion, shipped as a DeepSeek Harness skill.

- [`cp-notebooker/`](cp-notebooker/) — the skill itself (`SKILL.md` + `README.md`).
- [`bundle/`](bundle/) — npm bundle scaffold (`cp-notebooker-skill` plugin + `cp-notebooker-bundle`).

Notes and the tag vocabulary are generated in whichever project the skill runs in, not in this repository (see the skill's `SKILL.md`).
