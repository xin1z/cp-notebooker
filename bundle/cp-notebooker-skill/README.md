# @xin1z/cp-notebooker-skill

Bundled skill provider for [cp-notebooker](https://github.com/xin1z/cp-notebooker).

Install it through the bundle:

```bash
dsh plugin --profile <name> add @xin1z/cp-notebooker-bundle
```

The provider registers the `cp-notebooker` skill from `assets/cp-notebooker.md`.
That asset is generated from `cp-notebooker/SKILL.md` in the repository; do not
edit it directly.

Requires DeepSeek Harness `>=0.2.2-rc.1 <0.3.0`.
