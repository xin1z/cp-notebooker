# @xin1z/cp-notebooker-bundle

Installs the [cp-notebooker](https://github.com/xin1z/cp-notebooker) skill in a
DeepSeek Harness profile.

```bash
dsh plugin --profile <name> add @xin1z/cp-notebooker-bundle
```

Or in the Web UI: **Plugin Manager → install bundle → `@xin1z/cp-notebooker-bundle`**.

Requires DeepSeek Harness `>=0.2.2-rc.1 <0.3.0`.
